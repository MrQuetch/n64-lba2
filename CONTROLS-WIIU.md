# Wii U GamePad controls

All bindings can be changed in-game (Options → Controls → Configure gamepad).
Defaults:

## Buttons

| Input            | Action                                   |
|------------------|------------------------------------------|
| Left stick       | Move (up/down walk, left/right turn)     |
| D-pad            | Move (mirrors the left stick)            |
| ZR / ZL          | Walk forward / backward (secondary)      |
| A                | Action (use/talk/search)                 |
| X                | Action (behaviour move: jump, punch, …)  |
| Y                | Inventory                                |
| B                | Close menus / cancel                     |
| R                | Throw the magic ball / use weapon        |
| L                | Behaviour menu                           |
| Start (+)        | In-game menu                             |
| Select (−)       | Holomap                                  |
| L3 (stick click) | Dodge                                    |
| R3 (stick click) | Recenter camera                          |
| Right stick ↑/↓  | Camera level up / down                   |

Spells, the Protopack/Jetpack and the meca-penguin are on the GamePad
touch panel (below) or via the inventory.

## Touch panel (GamePad screen)

While playing, the GamePad screen shows three rows of touch shortcuts:

- **Behaviours** — Normal, Sporty, Aggressive, Discreet
- **Weapons** — Magic ball, Darts, Blowgun, Conch, Glove, Laser pistol, Sabre
- **Actions** — Holomap, Protopack, Protection, Lightning, Meca-penguin

Save names are entered with an on-screen keyboard driven by the touch panel
or the D-pad.
